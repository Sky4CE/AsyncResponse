# Security Policy

## Supported versions

AsyncResponse is pre-1.0. Security fixes are released against the latest published version on
the current `0.x` line. Older pre-release versions are not patched — upgrade to the latest.

## Reporting a vulnerability

**Please do not open a public issue for security vulnerabilities.**

Report privately through GitHub's [private vulnerability reporting][report] for this repository.
That opens a confidential advisory visible only to the maintainers.

[report]: https://github.com/Sky4CE/AsyncResponse/security/advisories/new

Please include:

- the affected package(s) and version(s),
- a description of the issue and its impact,
- steps to reproduce (a minimal repro or failing test is ideal).

## What to expect

- Acknowledgement of the report within a few days.
- An assessment and, where confirmed, a fix on the latest `0.x` line, coordinated with you on
  disclosure timing.
- Credit in the release notes and advisory unless you prefer to remain anonymous.
